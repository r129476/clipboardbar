ClipboardBar 剪贴板工具 1.0

适用系统：macOS 14 或更高版本；Apple 芯片（M 系列）Mac。
这是个人开发、用于作品展示的演示版本，尚未通过 Apple 公证。

使用方法
1. 解压后，将 ClipboardBar.app 放到「应用程序」文件夹。
2. 打开应用后，点击菜单栏的剪贴板图标。
3. 复制文字或图片后，应用会记录历史；点击记录可重新复制，再到目标应用粘贴。
4. 支持文字搜索、置顶、去重、删除；历史保存在本机。
5. 如 macOS 阻止打开，请先确认下载来源，并按系统提示处理。

本包仅含应用和此说明，不包含开发者的剪贴板历史、图片库或工作话术。
作品截图中的话术是专门制作的展示示例。
